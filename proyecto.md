# LABORATORIO – INDIVIDUAL - 1

El laboratorio consiste en desarrollar un sistema que contenga un **Editor de Texto**, donde el usuario ingresará una serie de palabras. Al finalizar, deberá presionar **F5** para realizar el conteo de palabras y vocales.

## SOLICITUD

1.  **Editor de Texto:** El programa debe contar con un espacio para la edición de texto e identificar cuántas **palabras** y **vocales** contiene el texto ingresado.
2.  **F5:** Una vez finalizada la escritura, el usuario utilizará la tecla **F5** para calcular las siguientes matrices:
3.  **Matriz de Entradas:** Debe diseñar una matriz en pantalla que despliegue la cantidad de palabras encontradas y la cantidad de vocales encontradas. (Nota: Contar solo 1 vez cada vocal diferente).
4.  **Matriz de Vocales:** Por cada vocal que se encuentre en el texto, debe indicar cuántas veces apareció. Si una vocal no aparece en el texto, no debe desplegarse en la matriz.
5.  **Signos de Puntuación:** Los signos de puntuación (punto `.`, coma `,`, punto y coma `;`, dos puntos `:`) **no** deben contarse como palabras.

## DISEÑO

1.  **Vista Única:** Mostrar todo en una sola vista. No se permite el uso de barras de desplazamiento (scrollbar) en la pantalla principal ni mostrar varias ventanas. (Incumplimiento: -10% de la nota).
2.  **Paleta de Colores:** Se permite usar colores únicamente para resaltar o para títulos, no para fondos. Se permite un máximo de **2 colores**. (Penalización: -10%).
3.  **Programación:** Debe utilizar un lenguaje de programación **orientado a objetos**. Si se presenta en consola o de forma estructurada, la nota se reducirá en un 10%.
