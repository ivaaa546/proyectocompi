# Dependencias del Proyecto (Polaris)

Para compilar y ejecutar este proyecto de interfaz gráfica, el **único** requisito que debes instalar en tu computadora es:

1. **[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)**

### Paquetes Internos (Automáticos)
Al compilar, .NET descargará **automáticamente** de NuGet lo siguiente (no necesitas instalarlo manualmente):
*   `Avalonia UI` (v11.3.12) - Para la interfaz gráfica.
*   `CommunityToolkit.Mvvm` (v8.2.1) - Para el patrón arquitectónico.

### Instrucciones de Ejecución
Desde tu terminal, en la carpeta raíz `proyectocompi`, ejecuta:
```bash
dotnet run --project EditorTexto/EditorTexto.csproj
```

## Ejecutar
Ejecutar dentro del directorio de la carpeta EditorTexto: dotnet run
